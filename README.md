# Hash Maps

Python implementations of hash maps using two collision resolution strategies:

- **Separate chaining** with singly linked lists
- **Open addressing** with quadratic probing

## Contents

- `hash_map_sc.py` – Separate chaining implementation
- `hash_map_oa.py` – Open addressing implementation
- `a6_include.py` – Supporting data structures used by the implementations

## Features

- Dynamic resizing
- Prime-sized hash tables
- Insert, update, lookup, and removal operations
- Load factor management
- Iteration support for the open addressing implementation
- Mode-finding utility built using the separate chaining hash map
